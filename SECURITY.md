# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities **privately** through GitHub private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**, or go directly to <https://github.com/jabbas/generated-secrets-operator/security/advisories/new>.

Do not open a public issue or pull request for a security problem.

Include the version, a description and, if possible, a way to reproduce the problem. Never include real secrets.

## Supported versions

Only the latest minor release series receives security fixes (currently `0.2.x`).

## More information

The threat model, the value redaction guarantees and the release signing are described in [docs/security.md](docs/security.md).
